# AtCoder Rust 練習コード・テンプレート

自分の競技プログラミング練習用のRustコードと、コンテスト前に用意したテンプレートを置く公開リポジトリです。

## 内容

- `src/main.rs`：最小限の `main` 関数。入力例はすべてコメントアウトしてあります。
- `snippets/dsu.rs`：Union-Find（DSU）の部品。使う場合は必要な部分を提出コードへコピーします。
- `practice/`：これから自分で書く練習コードの置き場所。問題文・サンプル入出力・個人の進捗データは置きません。

このリポジトリには、保存済み問題文、サンプルデータ、他の解答例、練習ダッシュボードを含めません。

## 動作確認

```text
cargo check
rustc --test snippets/dsu.rs -o dsu_test.exe
```

`src/main.rs` は現在、何も出力しません。必要な入力処理を自分で有効にし、問題ごとに書き足して使います。

## コンテスト中にコードを使う場合

テンプレートには生成AIを使って作成したコードが含まれます。AtCoderの[生成AI対策ルール](https://info.atcoder.jp/entry/llm-rules-ja)を、参加するコンテストの直前に確認してください。2026年10月時点のルールでは、コンテスト開始前にAI作成コードをWeb公開し、コピーして使う場合は提出ソースコード内に参照URLを記載する必要があります。公開日時とコードの内容を第三者が確認できる状態にしておきます。コンテスト中のAIによるコード補完・解法作成・デバッグは使いません。
